# Fase C (RBAC + MFA/TOTP): pyotp implementa RFC 6238 (TOTP) -- não
# reinventado à mão pelo mesmo motivo que este projeto usa `bcrypt`/`pyjwt`
# em vez de hash/JWT escritos do zero (ver auth/security.py). `cryptography`
# fornece Fernet (AES-128-CBC + HMAC autenticado) para cifrar o segredo TOTP
# em repouso (auth/mfa.py) -- ao contrário de uma senha, o segredo TOTP
# precisa ser recuperável em claro para calcular o código esperado a cada
# validação, então bcrypt (one-way) não serve para ele; Fernet é a escolha
# padrão da própria comunidade Python para "preciso descriptografar depois"
# sem implementar AES/HMAC manualmente.
pyotp==2.9.0
cryptography==47.0.0
